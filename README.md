# HotelApp - Java Swing (Simple PBO Project)

Project sederhana untuk mata kuliah PBO (Java) tanpa database.  
Fitur: Registrasi, Login, Booking, Pembayaran, Check-in, Check-out.  
Konsep OOP: visibility, inheritance, polymorphism, association, aggregation, composition, abstract, interface (minimal), nested class (can be extended).

## Struktur
- src/hotelapp/... (kode sumber)

## Cara compile & run
1. Buka terminal, masuk folder `src`
2. Compile: `javac hotelapp/**/*.java`
3. Run: `java hotelapp.Main`

Data disimpan sederhana ke file `hotel_data.ser` di working directory.

Enjoy!
